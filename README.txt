KASHIF × NAZNEEN — CINEMATIC PROPOSAL SITE

HOW TO OPEN
1. Extract the ZIP file.
2. Keep the assets folder in the same place as index.html.
3. Double-click index.html to open it in Chrome or another modern browser.
4. Tap “Let's begin” to start the story and soundtrack. The music button at the bottom can pause or play the song.

WHAT'S INCLUDED
- Mobile-first, portrait proposal experience
- Four swipeable scenes with progress dots and navigation
- Custom animated record-style soundtrack control (not a standard audio bar)
- Your supplied proposal video and song embedded locally
- Playful runaway “No” button
- Yes thank-you screen with WhatsApp share action

SHARING
To let Nazneen open the website from WhatsApp, upload the extracted folder to a static hosting service (for example, Cloudflare Pages or Netlify) and share the public website URL. The WhatsApp button uses the page's live URL after hosting.

NOTE
The “No” button is intentionally playful and dodges taps/clicks. The close (×) control remains available, and the page includes a no-pressure message.
